# Python Port & IP Scanner

Sebuah *tool* berbasis Python untuk melakukan *information gathering* dan pemindaian jaringan. 

## Fitur Utama
- **Subdomain to IP Resolution**: Memeriksa dan mengekstrak IP Address dari sebuah subdomain/hostname.
- **Custom Port Scanning**: Memindai rentang *port* spesifik secara dinamis sesuai masukan pengguna.
- **Multithreading**: Proses pemindaian berjalan cepat secara paralel.

## 🛠️ Cara Penggunaan
Jalankan skrip menggunakan Python 3:
```text
python3 port_scanner_and_ip.py
